# Simple Calculator

A beginner-friendly calculator built with HTML, CSS, and JavaScript. The code is completely handwritten, with no frameworks or libraries.

## Overview

This project is my first basic web calculator, that performs everyday arithmetic in the browser. It was built to practice core front-end skills: structuring a page with HTML, styling it with CSS, and adding logic with JavaScript. It was a test of what I learned from the university WAD course. Further WAD projects are in the link given below:

[https://github.com/zirconium001/university-projects/WAD_project/](https://github.com/Zirconium001/University-Projects/tree/main/WAD_project)

## Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear (C) and delete (⌫) buttons
- Clean, responsive layout
- Runs in any modern browser with no setup

## Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Page structure and buttons |
| CSS3 | Layout and styling |
| JavaScript (ES6) | Calculator logic and events |

## How to Use

1. Click the number buttons to enter a value.
2. Choose an operator (`+`, `-`, `×`, `÷`).
3. Enter the second number.
4. Press `=` to see the result.
5. Use `C` to clear everything or `⌫` to remove the last digit.
